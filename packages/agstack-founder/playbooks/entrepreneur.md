> **Trigger & Intent:** Business idea validation, community discovery, lean MVP scoping, first customers, pricing, sustainable growth — the Minimalist Entrepreneur framework.
> **Deliverable:** Whatever the `entrepreneur` skill prescribes for the task.

This playbook is a router, not a procedure. The work lives in the `entrepreneur` skill shipped in the `agstack-founder` package.

1. If the `entrepreneur` skill is installed, load it (`skills/entrepreneur/SKILL.md` in this package) and follow it in full.
2. If it is not installed, stop and tell the user: "This task routes to the `entrepreneur` skill in the `agstack-founder` package. Install `agstack-founder` to run it." Do not improvise a substitute.
