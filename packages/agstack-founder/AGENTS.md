# agstack-founder: Founder & Executive Policy

`agstack-founder` carries the non-engineering half of the agstack process: idea validation, lean startup execution, and executive reviews. Install it alongside `agstack`; the core policy in `agstack/AGENTS.md` (verification, no-comments, boundary discipline) applies unchanged here.

---

## 1. Skills

- **`entrepreneur`:** Business idea validation, community discovery, manual processizing, weekend MVP scoping, first 100 customers, pricing models, sustainable growth, and company values (Sahil Lavingia Minimalist Entrepreneur framework).
- **`gstack`:** Garry Tan executive review suite — YC office hours (product reframing), CEO review (10-star product), Design/DevEx/Eng reviews, and Autoplan pipeline.

## 2. Playbooks

- **`entrepreneur`:** routes to the `entrepreneur` skill; prompts for `agstack-founder` installation when absent.
- **`gstack-review`:** routes to the `gstack` skill; prompts for `agstack-founder` installation when absent.

## 3. Install-prompt rule

When a task routes to a skill or playbook in this package and the package is not installed, stop and name the package to install (`agstack-founder`). Do not improvise a substitute procedure.
